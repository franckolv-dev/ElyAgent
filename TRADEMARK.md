## 4. If you fork

Forking is welcome — the project is open source for a reason. But your fork must:

1. **Use a different name.** Examples acceptable: *"NeuroBot"*, *"MyAgent"*, *"FranckBot-Custom"*. Examples unacceptable: anything starting with *"Ely"* or containing *"agent-ely"*.
2. **Replace the avatar and logo** with your own. The wireframe head and lightning bolt are off-limits.
3. **Keep the LICENSE and a NOTICE** crediting the original ELY project (MIT requires the copyright notice anyway).
4. **Make it clear it's a fork** — a line in your README like *"Fork of ELY by Franck OLLIVIER, see [original repo](https://github.com/franckolv-dev/ElyAgent)"* is sufficient.

We will not pursue forks that follow these rules — that's open source done well.

## 6. Enforcement

We monitor :
- The npm, PyPI, Docker Hub registries for packages using the ELY name
- GitHub for repositories that reuse the avatar / logo
- The web for unauthorized "ELY" branded products

Detected violations get a graduated response :

| Step | What happens |
|---|---|
| 1. **Friendly notice** | Email asking you to rename / remove. Most cases resolve here. |
| 2. **Cease & Desist** | Formal letter from our IP counsel. ~80% of remaining cases resolve here. |
| 3. **DMCA / hosting takedown** | We notify GitHub / Docker Hub / npm / your registrar. Content removed in 24-72h. |
| 4. **Legal action** | Trademark + license breach in commercial competition territory. Damages start at the cost of our enforcement plus your unfair profit. |

We are **not** litigious by default — we much prefer step 1. But we will use steps 2-4 when a commercial actor knowingly profits off our work.
