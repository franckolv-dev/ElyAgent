# 🤖 ELY Agent : L'Assistante IA Souveraine & Auto-Évolutive

> **La sécurité n'est pas une option, c'est l'architecture.**

ELY est une assistante autonome de nouvelle génération conçue pour ceux qui refusent de choisir entre **puissance technologique** et **confidentialité absolue**. Contrairement aux autres agents qui servent de simples passerelles vers les LLM, ELY agit comme un "pare-feu intelligent" et un binôme capable de créer ses propres outils.

---

## 🚀 Pourquoi ELY ? (Le "OpenClaw Killer")

Si OpenClaw excelle dans la connectivité multi-canaux, **ELY** redéfinit ce qu'un agent autonome peut faire sur votre propre machine avec une sécurité sans compromis.

| Fonctionnalité | ELY Agent | La Concurrence (OpenClaw, etc.) |
| :--- | :--- | :--- |
| **Confidentialité** | **Filtre PII Natif** : Vos données sensibles (CB, IBAN, Emails) sont anonymisées *avant* de quitter votre PC. | Données envoyées en clair au LLM Cloud. |
| **Auto-Évolution** | **Génération Dynamique MCP** : ELY peut coder ses propres outils pour piloter n'importe quel logiciel. | Limité aux plugins pré-installés. |
| **Intelligence** | **Routage Hybride LLM/SLM** : Utilise Ollama en local pour le simple, le Cloud pour le complexe. | Dépendance quasi-totale aux API coûteuses. |
| **Apprentissage** | **Mémoire Hybride Long Terme** : Analyse sémantique + Recherche plein texte + Décroissance temporelle. | Mémoire vectorielle simple (souvent brouillonne). |
| **Interaction** | **Interactive Trainer** : ELY voit votre écran et vous montre comment faire (Blender, Photoshop, etc.). | Principalement limité au texte et au web. |
| **Secrets** | **Local Vault** : Vos mots de passe sont chiffrés localement et injectés sans être lus par l'IA. | Secrets souvent stockés en clair ou via API cloud. |

---

## 🔥 Fonctionnalités Phares

### 🛡️ Security-First Architecture
ELY intègre un `SecurityFilter` qui détecte et remplace les informations personnelles par des jetons opaques. La dé-anonymisation ne se fait qu'à l'affichage final sur votre écran. Votre vie privée reste privée.

### 🛠️ Dynamic Tooling (MCP)
Besoin de piloter un logiciel métier obscur ? ELY analyse l'application, génère un serveur **Model Context Protocol (MCP)** sur mesure, l'installe et l'utilise. Elle est la première IA capable d'étendre son propre "corps" logiciel de manière autonome.

### 🐍 Sandbox Python Ultra-Sécurisée
Exécutez des analyses de données complexes en local. Le bac à sable d'ELY utilise une analyse AST (Abstract Syntax Tree) pour bloquer toute commande système ou réseau malveillante avant exécution.

### 🧠 Mémoire Épisodique & Sémantique
ELY n'oublie pas ce qui est important. Elle apprend vos préférences, vos habitudes de travail et vos contraintes de sécurité au fil des conversations, tout en ignorant le bruit inutile grâce à son algorithme de décroissance temporelle.

## 🛠️ Installation & Usage
*(Voir [installation.md](docs/installation.md) pour les détails techniques)*

ELY tourne sur votre machine via Docker, utilise SQLite pour vos données et Qdrant pour sa mémoire vectorielle. Elle est compatible avec **Ollama** pour une souveraineté totale.
