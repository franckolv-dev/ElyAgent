ELY · Browser Companion

Pour qu'Ely puisse agir dans ton navigateur, donne-lui l'adresse de ton instance et un jeton d'accès (généré dans ELY → Réglages → Extension navigateur). Aucune information ne sort de ce poste tant que le jeton n'est pas posé ici.

1. Adresse de ton ELY

Sans slash final. Exemple : https://ely.catalogmaker.fr.

2. Jeton d'accès (JWT)

Le token est stocké uniquement dans le storage de ton navigateur (chiffré par Chrome). Il n'est jamais envoyé à un tiers — seule ton instance ELY le voit.

3. Statut

—

ELY est libre (PolyForm Strict 1.0). Cette extension fait partie du projet — code source sur github.com/franckolv-dev/ElyAgent.
