ELY · Browser Companion

Pour qu'Ely puisse agir dans ton navigateur, donne-lui l'adresse de ton instance et un jeton d'accès (généré dans ELY → Réglages → Extension navigateur). Aucune information ne sort de ce poste tant que le jeton n'est pas posé ici.

1. Adresse de ton ELY

Sans slash final. Exemple : https://ely.catalogmaker.fr.

2. Jeton d'accès longue durée

Recommandé. Génère un token longue durée (format ely_ext_…) qui survit aux redémarrages de Chrome. Plus jamais besoin d'ouvrir DevTools.

Le token est stocké uniquement dans le storage local du navigateur. Il n'est jamais envoyé à un tiers — seule ton instance ELY le voit. Les tokens ely_ext_ n'expirent pas ; tu peux les révoquer à tout moment depuis ELY → Réglages → Extension navigateur.
